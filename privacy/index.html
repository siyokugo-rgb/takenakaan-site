プライバシーポリシー

最終更新: 2026年9月11日

本ポリシーは、「竹中庵 / Takenakaan」（読み: たけなかあん。以下「本名称」）のもとで、運営者本人が利用する個人用開発ツール（以下「本ツール」）および本サイトにおける情報の取扱いを説明します。本名称は個人によるソフトウェア・アプリケーション開発の名称であり、現時点で法人ではありません。

1. 対象

本ツールは、原則として運営者本人が使用する個人用開発ツールです。第三者向けの一般公開サービスとして運営することを目的としていません。

2. Google Drive API の利用

本ツールは、開発作業に必要な範囲で Google Drive API を利用し、Google アカウントに紐づくファイルの検索、読取、アップロード、ダウンロード等を行う場合があります。

利用する権限と用途は、必要最小限に限ります。

3. Google ユーザーデータの取扱い

本ツールが Google API 経由で取得するデータ（以下「Googleデータ」）について、次のとおり取り扱います。

  • Googleデータを広告目的で使用しません。
  • Googleデータを販売しません。
  • 不要な第三者提供を行いません。
  • 法令に基づく場合など、やむを得ない場合を除き、開発目的の達成に必要でない第三者へ提供しません。

本ツールは、Google API Services User Data Policy および Limited Use 要件を遵守します。

4. Googleユーザーデータの保存・保持

Google Driveから取得したファイルは、開発作業に必要な範囲で、開発環境へ一時的にダウンロードし、処理する場合があります。

Google Drive外でGoogleユーザーデータを不必要に恒久保存することを目的としません。

開発作業上必要なくなった一時データは、利用環境のライフサイクルに応じて削除・破棄します。

ユーザーが明示的に保存先として指定した Google Drive 上のファイルは、その Google Drive 内に保持されます。

認証情報の扱いについては、後述の「認証情報の管理」に従います。

5. 認証情報の管理

OAuth token、refresh token、client secret 等の認証情報は、公開リポジトリへ保存しません。これらの情報は、運営者本人が管理する非公開の場所でのみ取り扱います。

6. アクセス権の取り消し

Google アカウントの設定から、本ツールに付与したアクセス権をいつでも取り消せます。取り消し後、本ツールは当該アカウントの Googleデータへアクセスできなくなります。

7. 本サイトで収集しない情報

本サイトは、現時点でフォーム、Cookie、独自のアクセス解析を使用しません。閲覧時の通信は、ホスティング事業者の通常の処理に委ねられます。

8. 改定

機能追加や利用範囲の変更がある場合は、必要に応じて本ポリシーを更新します。更新後の内容は、本ページに掲載した時点から適用します。
